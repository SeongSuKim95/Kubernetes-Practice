# Chapter 4 English figures

The current publication follows **Pod Execution and Status Checks**, with Fig 1–6.
Its four animations are generated by the shared bilingual Python renderers:

```sh
/usr/bin/python3 scripts/publication/render-ch04-lifecycle.py --en
/usr/bin/python3 scripts/render-chapter04-probe-flows.py --en
```

See [the publication workflow](../publication/README.md) for rebuilding both
languages and checking publication parity, images, references, and GIF frames.

The Swift renderers and the Node recovery/Pending generators in this directory
are retained for earlier assets. They do not define the current chapter 4
layout or scope. The current lifecycle renderer reads the English stage text
from `render-ch04-fig3.swift` and `render-ch04-status.swift`.
